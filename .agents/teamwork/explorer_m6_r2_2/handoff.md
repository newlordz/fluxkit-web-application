### 1.4 Async Race Condition on Rapid Whiteboard Undo/Redo (`src/ToolPage.tsx:679–713`)
- **Direct Code Observation (`src/ToolPage.tsx:679–713`)**:
  ```typescript
  function handleWhiteboardUndo() {

- **Observed Behavior**:
  `handleWhiteboardUndo` and `handleWhiteboardRedo` dispatch asynchronous `new window.Image()` decode requests with `img.onload`. Rapid consecutive Undo or Redo calls (e.g. repeated `Ctrl+Z` keystrokes) initiate parallel decodes. Because data URL decoding duration varies, a prior snapshot's `onload` callback can execute after a later snapshot's callback, leaving the canvas displaying an older or wrong history snapshot.

## 2. Logic Chain

1. **Storage Robustness**:
   - `sessionStorage.getItem()` returns `string | null`. When set to `"null"` or corrupted data, `JSON.parse` evaluates to `null` or non-array primitives.
   - Checking `const parsed = JSON.parse(stored); if (Array.isArray(parsed)) list = parsed;` ensures `list` remains an array (`[]`), preventing `TypeError: Cannot read properties of null (reading 'length')`.

2. **Category Precedence**:
   - The file extension represents the actual physical format of the generated file (e.g. `.xlsx` is always a spreadsheet).
   - Evaluating known extensions (`.pdf`, `.xlsx`, `.pptx`, `.png`, `.srt`, `.docx`) first, and falling back to `toolSource` keywords only when the extension is absent or unrecognized, ensures that conversion outputs like `financials.xlsx` are categorized as `"sheets"` even if generated from `PDF to Excel`.
   - When updating `src/services.ts`, the empirical assertion in `tests/challenger-m6-adversarial.test.cjs:371` must be aligned from `"pdf"` to `"sheets"` so the regression test passes.

3. **Whiteboard Pointer Boundary Safety**:
   - Canvas pointer events trigger `onPointerLeave` when a user drags beyond the element edges.
   - If `isDrawingRef.current` is true, drawing was active when leaving. Committing the stroke (`whiteboardHistoryRef.current.push(canvas.toDataURL("image/png"))`) before resetting `isDrawingRef.current = false` preserves the stroke in history.

4. **Monotonic Sequence for Undo/Redo**:
   - Introducing `whiteboardRenderSeqRef = useRef<number>(0)` provides a monotonically increasing request token.
   - Incrementing `renderSeq = ++whiteboardRenderSeqRef.current` at the start of `handleWhiteboardUndo` and `handleWhiteboardRedo`, and checking `if (renderSeq !== whiteboardRenderSeqRef.current) return` inside `img.onload`, guarantees that only the latest requested snapshot renders to the canvas. In-flight stale decodes are dropped.

5. **Clean Meetings Service Wiring**:
   - Initializing `chatMessages` via `createMeetingState().chatMessages` ensures consistent initial state.
   - Consolidating chat dispatch into `handleSendMeetingChat(text: string)` using `sendChatMessage(state, sender, text)` eliminates duplicate code between `Enter` key and `Send` button, guarantees non-empty validation, and connects `src/services.ts`.
   - Updating UI copy to describe the viewport as a "Simulated HD virtual meeting stage with mock stream & animated equalizer" ensures absolute transparency.

// AFTER:
export function detectDocumentCategory(
  filename: string,
  toolSource = "",
): string {
  const parts = filename.toLowerCase().split(".")
  const ext = parts.length > 1 ? parts.pop() || "" : ""

  // Priority 1: Check known file extensions first
  if (["pdf"].includes(ext)) return "pdf"
  if (["xlsx", "xls", "csv"].includes(ext)) return "sheets"
  if (["pptx", "ppt"].includes(ext)) return "slides"
  if (["png", "jpg", "jpeg", "webp", "gif", "svg"].includes(ext)) return "images"
  if (["srt", "mp3", "wav", "m4a", "ogg"].includes(ext)) return "audio-text"
  if (["docx", "doc", "txt", "rtf", "md"].includes(ext)) return "docs"

  // Priority 2: Fall back to toolSource keywords when no extension or unrecognized extension
  const src = toolSource.toLowerCase()
  if (src.includes("excel") || src.includes("sheet") || src.includes("csv"))
    return "sheets"
  if (
    src.includes("powerpoint") ||
    src.includes("ppt") ||
    src.includes("slide")
  )
    return "slides"
  if (
    src.includes("whiteboard") ||
    src.includes("image") ||
    src.includes("photo")
  )
    return "images"
  if (
    src.includes("audio") ||
    src.includes("voice") ||
    src.includes("transcript")
  )
    return "audio-text"
  if (src.includes("word") || src.includes("doc"))
    return "docs"
  if (src.includes("pdf"))
    return "pdf"

  return "other"
}
```
